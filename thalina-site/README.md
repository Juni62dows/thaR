# Thalina — сайт

Готовый адаптивный одностраничный сайт по предоставленному промту.

## Структура
- `index.html` — весь сайт и контент
- `style.css` — дизайн, адаптивность и анимации
- `script.js` — мобильное меню, фильтры каталога, модальное окно и форма
- `assets/mascot-reference.png` — предоставленный пользователем референс маскота

## Запуск
Просто откройте `index.html` в браузере.

## Важно
Сейчас изображения продукции и сцены выполнены CSS-артом/градиентами, как предусмотрено промтом.
На местах маскота оставлены аккуратные зоны для будущих сгенерированных иллюстраций:
1. с бокалом вина;
2. с коробкой конфет;
3. на фоне виноградника;
4. в кондитерском фартуке.

Цены в каталоге не используются.
